# File Complaints

For any concerns pertaining to consent or data authorization preferences, file a complaint.

To file, click ![](<../../.gitbook/assets/image (3) (1) (1) (1).png>)  and

* Select the category,
* Date on when you encountered it,
* Describe your concern in detail,
* Attach a file (size < 10MB) in supported formats, and
* Select the preferred resolution.

Then, click **Submit Complaint**.&#x20;

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Raise a complaint.png" alt=""><figcaption></figcaption></figure></div>

After submitting a complaint, you can track its status in "Privacy Requests & Complaints" page.

To view, select **Privacy Requests & Complaints** in the menu or select <img src="../../.gitbook/assets/image (2) (1) (1) (1) (1) (1) (1).png" alt="" data-size="original"> in the left navigation pane.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Privacy Requests &#x26; Complaints.png" alt=""><figcaption></figcaption></figure></div>

Track the status of your complaints here. To view any complaint details, select **Open.**

If you have any queries or to follow up, you can use the chat option and start conversing.
