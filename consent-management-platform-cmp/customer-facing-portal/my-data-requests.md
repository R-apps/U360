# My Data Requests

The **My Data Requests** page lets you submit and track requests related to your personal data. It provides a centralized view of all requests, including their current status and submission details.

Use this page to monitor the progress of your requests and review previously submitted requests.

To view, select **Data Requests** in the menu or from the left navigation pane.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/My Data Requests.png" alt=""><figcaption></figcaption></figure></div>

### Manage Requests

#### View Request Details

Navigate to the request in the table and select **View**. The porta displays the request details such as the date on which you raised the request, SLA date, and its current status, as shown in the illustration below:

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/My Data Requests - View Details.png" alt=""><figcaption></figcaption></figure></div>

#### Raise a New Data Request

To raise a new data request,

* Select **New Request**&#x20;
* Choose the type of request you want to submit.
* Provide the required information such as field data/element, category, and description.
* Review and then select **Submit Request**.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/New Data Request.png" alt="" width="563"><figcaption></figcaption></figure></div>

The portal acknowledges your data request as illustrated below:

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/New Data Request - Acknowledge.png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Refresh the List

Select **Refresh** to load the latest request information.

#### Customize the View

Select **View** (display options) to customize how requests are displayed in the table.

### Request Statuses

The status indicates the current stage of your request.
