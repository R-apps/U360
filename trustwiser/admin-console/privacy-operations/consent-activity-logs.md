# Consent Activity Logs

The **Consent Activity Logs** provides a complete audit trail of all consent-related actions and updates.&#x20;

It displays detailed records of consent changes made by or for customers. It ensures compliance and audit readiness, provides full visibility into customer consent changes, and enable data export for reporting and governance

Example: If a customer updates his/her communication preference by disabling Email notifications, the system records the change instantly, the log captures both **old value (Enabled)** and **new value (Disabled)**, and the **source** reflects whether the action was performed via portal or API.

This ensures full traceability of every consent change.

### Manage Logs

* Select **Refresh** to retrieve the latest records.
* Use **Filter** (![](<../../../.gitbook/assets/FIlter icon.png>)) to view the records with required Action (Granted / Revoked / Updated / Created)
* Select **Export** to download data offline in PDF.
* Use **Search** option to search activity logs of a specific customer using the Customer ID. To export that data, select **Export Customer**.
* Consent proof or the consent certificate is attached for every consent activity. To view, select **View** corresponding to the required activity.
