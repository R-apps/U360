# Overview

This provides a centralized view of data discovered across connected enterprise data sources. It helps organizations identify and classify sensitive data, measure classification coverage, monitor data source health, track classification and mapping activities, and identify unclassified data that may require further attention.

The dashboard combines rule-based detection and AI-powered classification to provide visibility into how much data has been classified and where additional review may be required.

To view, navigate to **Data Discovery & Classification** > **Overview**.

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Data Discovery &#x26; Classification - Overview.png" alt=""><figcaption></figcaption></figure></div>

This provides insights on the following:

* **Data Sources** – The number of connected data sources available for discovery and analysis.
* **Classification Runs** – The number of classification jobs performed and their results.
* **Mapping Runs** – The number of data mapping jobs performed and their results.
* **Categories** – The number of configured data classification categories and rules.
* **Classified Columns** – The number of data columns that have been classified compared with the total number of columns identified.
* **Coverage** – The percentage of identified columns that have been classified across connected data sources.
* **Action Items** – Highlights classification failures, unclassified columns at risk, and data sources that may require attention.
* **Last Classification Run** – Shows the details and result of the most recent classification job.
* **Last Mapping Run** – Shows the details and result of the most recent data mapping job.
* **Unclassified Risk Surface** – Shows columns that do not have a classification result and may require review.
* **Sensitive Column Exposure** – Shows the distribution of classified columns by sensitivity level.
* **Coverage Trend** – Shows how classification coverage changes over time.
* **Classification Runs Over Time** – Shows classification activity across the selected period.
* **Run Status Summary** – Shows the number of classification runs by status, such as completed or failed.
* **Classification by Category** – Shows the distribution of classified and unclassified columns across data categories.
* **Sensitivity Distribution** – Shows how classified columns are distributed across sensitivity levels.
* **Regulation Coverage** – Shows the number of columns associated with supported regulatory frameworks.
* **Mapping Coverage** – Shows the number of matched and unmatched columns for configured data mappings.
* **Data Source Health** – Shows the status, last scan, and classification coverage of each data source.
* **Recent Classification Runs** – Provides details of recent classification jobs, including the data source, status, tables processed, and columns classified.
