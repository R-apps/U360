# Data Sources

The **Data Sources** page lets you select the enterprise data sources that can be used for \
Data Discovery & Classification. Selected sources are displayed with basic information such as the source type, host, and number of classified items.

Use this page to control which configured enterprise data sources are available for classification. \
You can add data sources from Enterprise Connectivity, view their details, open the corresponding configuration in Enterprise Connectivity, or remove a source from the Data Discovery & Classification list.

<figure><img src="../../../../.gitbook/assets/Data Discovery &#x26; Classification - Datasources.png" alt=""><figcaption></figcaption></figure>

### Manage Data Sources

#### Add/Select Data Sources

Choose the enterprise data sources that you want to make available for data classification.

* Click **Select Data Source**.
* Select the check box next to each data source that you want to use for Data Discovery & Classification.
* Select **Add selected**.

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Data Discovery &#x26; Classification - Datasources (Select Datasource).png" alt=""><figcaption></figcaption></figure></div>

The selected data sources are added to the **Data Sources** page.

#### View Data Source Details

Select **View** on the required data source to review basic information such as the source type, host, and number of classified items.

#### Open in EC

To create or update a connection, select **Open in EC** or select **Enterprise Connectivity** for the corresponding data source.

#### **Remove a Data Source**&#x20;

Remove a selected source from the Data Discovery & Classification list when it is no longer required. To remove, select **Delete** (![](<../../../../.gitbook/assets/Delete Icon.png>)).

> **Note:** Removing a data source from this page only removes it from the Data Discovery & Classification list. It does not delete the corresponding enterprise data source from \
> **Enterprise Connectivity**.
