# AI-Powered Data Discovery & Classification

The **AI-powered Data Discovery & Classification** page provides a centralized view of data discovered across connected enterprise data sources. It helps organizations identify and classify sensitive data, measure classification coverage, monitor data source health, track classification and mapping activities, and identify unclassified data that may require further attention.

The dashboard combines rule-based detection and AI-powered classification to provide visibility into how much data has been classified and where additional review may be required.
