# Compliance & Audit Logs

The Compliance & Audit Logs section provides visibility into activities performed across the platform and API interactions.

It helps administrators monitor relevant events, review activity records, and maintain traceability of operations.

The section provides two views:

1. [Admin Activity](compliance-and-audit-logs.md#admin-activity)
2. [API Activity](compliance-and-audit-logs.md#api-activity)

### **Admin Activity**

This displays recorded activities performed within the platform. It provides an overview of the activity records and allows administrators to review the associated event details.

The interface includes the following summary information:

* **Activity**: Displays the total number of recorded audit activities.
* **API Activity**: Displays the number of API-related activity records.

The **Client Consent Activity** Logs table displays records associated with customer consent-related activities. These logs help organizations trace consent-related activities, understand what operations were performed, and review changes made to customer consent information.&#x20;

Use **Refresh** (![](<../../../../.gitbook/assets/Refresh icon.png>)) to retrieve the latest audit records.

Use **Export** (![](<../../../../.gitbook/assets/Export to Excel.png>)) to export the audit log information in PDF for further review.

Use **Actions filter** to filter the displayed records using the available action criteria.

### API Activity

API activity logs help administrators monitor system interactions, investigate integration-related issues, and understand the service calls associated with platform operations.

* The **API Activity** tab displays records associated with service calls and API-related operations.
* The **Service Call Updates** table provides information about recorded service call activities.

Use **Refresh** (![](<../../../../.gitbook/assets/Refresh icon.png>)) to retrieve the latest service call records.

Use **Export** (![](<../../../../.gitbook/assets/Export to Excel.png>)) to export the API activity information in PDF.
