# Sharing Partners

Manage third-party organizations or platforms that receive customer data for communication or service delivery. Configure each partner's visibility, default status, approval status, and activation.

All the added partners are displayed as cards with an option to edit, delete, activate/deactivate it. These cards even display the partner's name, visibility, current status, and other.

To access, got to **Privacy Foundation** > **Privacy Catalog** > **Sharing Partners**

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Sharing Partners.png" alt=""><figcaption></figcaption></figure></div>

### Add a New Sharing Partner

* Select **Add Partner**
* Enter the **Partner Name** and **Description**
* Select the **Consent purpose** and **Notice** (optional)&#x20;
* Select **Consent Expiry**, if required.
* Select what all personal information can be shared with the sharing partner. Based on the selected fields and their associated edit/delete permissions, risk level is derived.
* Specify the default consent behavior when no response is received
* Set default **Partner status** (Enabled/Disabled)

> Alternatively, you can pick a default partner from the right pane and customize it as required.

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Add Sharing Partner.png" alt="" width="563"><figcaption></figcaption></figure></div>

#### Adding Partners in Bulk

To add multiple sharing partners at once, select **Download Excel Template** (![](<../../../../.gitbook/assets/Download Excel Template icon.png>)) to download the template. Enter the fields details in the specified format and save the file.

Then, select **Import** (![](<../../../../.gitbook/assets/Import from Excel.png>)) and upload the excel file.

#### Run Assessment

The **Run Assessment** option allows an administrator or privacy owner to assess the privacy risks associated with sharing data with a particular partner, such as an insurance partner. The assessment helps evaluate whether the data sharing is necessary, justified, proportionate, and supported by appropriate risk controls.

This is available in the **Edit Partner** option. When you run it, it guides you through questions about the purpose and necessity of sharing data, the applicable legal basis, potential risks, and the controls in place to address those risks. The final Summary step brings the assessment results together so the user can review them before submission.

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Run Assessment.png" alt="" width="563"><figcaption></figcaption></figure></div>

### Manage Partners

* Use Visibility toggle to enable or disable the partner's visibility in the customer portal.
* To edit a partner's information, select **Edit** (![](<../../../../.gitbook/assets/Edit icon (1).png>)) on the card. Make necessary changes and save changes.
* Use **Delete** (![](<../../../../.gitbook/assets/Delete Icon.png>)) to remove a partner that is no longer required.
* Use **Refresh** (![](<../../../../.gitbook/assets/Refresh icon.png>)) to load all the partners added to date.
* To export the partners list to an excel file, select **Export** (![](<../../../../.gitbook/assets/Export to Excel.png>)).
* To rearrange, hover over a partner information card and use the **Drag to reorder** icon (![](<../../../../.gitbook/assets/image (34).png>)) to drag and place it in the required position.
* Switch between **Cards View** (![](<../../../../.gitbook/assets/Cards View icon.png>)) and **Table View** (![](<../../../../.gitbook/assets/Table View icon.png>)) to display the partners in your preferred layout.
