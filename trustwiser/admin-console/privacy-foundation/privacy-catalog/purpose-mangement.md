# Purpose Mangement

Define the purposes for collecting or processing personal data. Provide a name and description for each purpose and control its visibility and active status to support consistent purpose definitions across the platform.

Configured purposes are displayed as cards with purpose name, ID, description, and visisbility status.

To access, got to **Privacy Foundation** > **Privacy Catalog** > **Purpose Management**

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Purpose Management.png" alt=""><figcaption></figcaption></figure></div>

### Create a New Purpose

* Select **Add Purpose**.
* Enter the **Privacy Name** and a unique **Purpose ID**.
* Describe breifly the purpose.
* Then, select **Create Purpose** to save it.

<div align="left" data-with-frame="true"><figure><img src="../../../../.gitbook/assets/Add Purpose.png" alt=""><figcaption></figcaption></figure></div>

#### Adding Purposes in Bulk

To add multiple purpose at once, select **Download Excel Template** (![](<../../../../.gitbook/assets/Download Excel Template icon.png>)) to download the template. Enter the fields details in the specified format and save the file.

Then, select **Import** (![](<../../../../.gitbook/assets/Import from Excel.png>)) and upload the excel file.&#x20;

### Manage Purposes

* Use Visibility toggle to enable or disable the purpose's visibility in the customer portal.
* To edit a data field, select **Edit** (![](<../../../../.gitbook/assets/Edit icon (1).png>)) on the card to modify the purpose's details and configuration.
* Use **Delete** (![](<../../../../.gitbook/assets/Delete Icon.png>)) to remove a purpose that is no longer required.
* Use **Refresh** (![](<../../../../.gitbook/assets/Refresh icon.png>)) to load all the purposes added to date.
* To export the purposes to an excel file, select **Export** (![](<../../../../.gitbook/assets/Export to Excel.png>)).
* Switch between **Cards View** (![](<../../../../.gitbook/assets/Cards View icon.png>)) and **Table View** (![](<../../../../.gitbook/assets/Table View icon.png>)) to display the notices in your preferred layout.
