# Proforma Processing Configuration

**Proforma Processing** enables additional multi-processing capabilities for MPTs.

It reduces the need for repeated configuration when enabling or disabling features such as Indexing, Automation, and On-the-Fly processing.

To enable an MPT for proforma processing,&#x20;

* Access the **Process Configuration** dialog, right-click the MPT to be enabled, and select **Advanced Settings**
* Select the check box under the **Proforma** column.
*   Then, click **Ok**.<br>

    <div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/image (30) (1) (1).png" alt=""><figcaption></figcaption></figure></div>

Now, the selected MPT can be used for proforma processing.
