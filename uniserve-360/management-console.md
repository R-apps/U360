# Management Console

Automate file-based processing with FSpy.

FSpy introduces a file monitoring mechanism that continuously watches a configured source location for incoming files. When a new file becomes available, UniServe 360 automatically picks it up and initiates processing using the associated template and configuration.

Previously, users had to place files in a designated location and manually initiate the process. With FSpy, the monitoring and processing workflow is automated, enabling near real-time execution of batch processes as soon as files arrive.
