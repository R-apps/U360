# CHUB

Reach is available as a **Communications Platform as a Service (CPaaS)**, enabling enterprises to use its communication capabilities as on-demand services.

With Reach CPaaS, organizations can integrate communication channels programmatically and trigger customer communications directly from their applications, backend systems, or business processes. This allows teams to send messages at scale without building or maintaining channel-specific infrastructure.

The **Communication Hub (CHUB)**, is a core routing and orchestration layer within the ecosystem. It  is a central layer that receives communication requests from different systems, validates and routes them to the appropriate channels (SMS, Email, WhatsApp) through configured aggregators.&#x20;

#### How Enterprises can Use Reach CPaaS Services?

Enterprises can:

* Connect their internal systems to Reach using APIs
* Trigger communications based on system events or data updates
* Centralize communication handling instead of managing multiple vendors
* Use the same Reach platform for both **UI-based campaigns** and **API-driven communications**

Reach CPaaS acts as a **communication layer** between your systems and customer-facing channels.\
Your application sends data or instructions to Reach, and Reach handles:

* Message processing
* Channel routing
* Delivery execution
* Status and response handling (where applicable)

This approach reduces operational complexity and speeds up communication enablement.

Reach CPaaS works alongside the platform’s UI-based capabilities, giving you the flexibility to handle both **system-driven** and **campaign-based** communications in one place. UI-based communication remains suitable for planned or manual campaigns, while CPaaS supports system-driven communication needs.
