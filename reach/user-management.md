# User Management

We, the REACH team (Super Admin) creates an admin account for each customer (tenant), enabling them to onboard their team assigning necessary permissions to modules based on their users' roles, ensuring role-based access control (RBAC).

### Onboard User(s)

To onboard a new user,

* Go to **User Management** > **Create New User**
* Enter the user’s details such as Name, Email, Mobile No., Department, Password, and Address.



Next, go to the User Permissions tab to assign access permissions to the user. Here, you have multiple options to restrict users to view, or to create, or to delete, or to just run campaigns, and others. Considering your requirement, you can assign only the required permissions to the user, or in the case you choose to set all the permissions, you can simply check Select All option.

To assign permissions to the user,

Select a permission type in the left pane and enable necessary permissions.

&#x20;             E.g., For SMS campaigns, the user typically needs SMS, CSV, and database permissions.\
To grant SMS permissions, select SMS and choose the necessary permissions for transactional, promotional, template, and campaign managing permissions for that user.

![](file:///D:/Old%20Disk%20-%201/PRODUCTS/REACH/Reach%20-%20UM%20v%201.0/contents/assets/images/image37.png)

Make sure to select the country from where the user access the application.

Similarly, assign the required permissions to other modules to the user.

After you assign permissions, click Create User.

The user account is created along with a unique client Id.

To view the onboarded user, go to User Management > View Users. The application displays a list of onboarded users to date.
