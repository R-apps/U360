# Metering Details

Metering Details provides a summary and real-time insights into user consumption of application assets and transactional APIs across all channels.

To view the detailed information, click Show Details. The application displays the information as shown in the below illustration. You can also use the Search option to look for transactions that happened on a certain day or during a certain time frame.
