# Execute Rules

UniServe Reach allows you to execute single or multiple rules immediately, or schedule them to run automatically at a designated time.

To execute define rules, go to **Data Management** > **Rule Engine** > **Execute Rules**.

To execute a single rule,&#x20;

* select **Execute Now** (![Execute Now icon](<../../../.gitbook/assets/image (100).png>)) to execute it at that instance.
*   select **Schedule** (<img src="../../../.gitbook/assets/image (101).png" alt="" data-size="original">) to schedule its execution. Specify date and time to automate execution and then select **Schedule**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (103).png" alt="Scheduling a rule execution"><figcaption></figcaption></figure></div>

To execute multiple rules, check to select the rules to be executed.

* Select **Execute All Selected** to execute them at that instance.
*   Select **Schedule** to run at a specified date and time.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (104).png" alt="Process to execute multiple rules"><figcaption></figcaption></figure></div>
