# Execute Rules

UniServe Reach allows you to execute single or multiple rules instantly, or schedule them to run automatically at a designated time.

To execute rule(s), go to **Data Management** > **Rule Engine** > **Execute Rules**.

To execute a single rule,&#x20;

* select **Execute Now** (![Execute Now icon](<../../../.gitbook/assets/image (100).png>)) to execute it at that instance.
*   select **Schedule** (<img src="../../../.gitbook/assets/image (101).png" alt="" data-size="line">) to schedule its execution. Specify date and time to automate execution and then select **Schedule**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (103).png" alt="Scheduling a rule execution"><figcaption></figcaption></figure></div>

To execute multiple rules, check them to select, and then

* select **Execute All Selected** to execute them at that instance, or
*   select **Schedule** to run them at a specified date and time.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (104).png" alt="Process to execute multiple rules"><figcaption></figcaption></figure></div>

### Execution History

The **Execution History** tab provides an audit trail of all manual and scheduled rule executions. It tracks the performance, status, and timeline of your rule runs. Use this information to verify successful runs, review audience sizes, check who triggered a rule, and troubleshoot processing errors.

To view, switch to **Execution History** tab.

<div align="left"><figure><img src="../../../.gitbook/assets/image (105).png" alt=""><figcaption></figcaption></figure></div>

Quickly find specific execution records using the search parameters.

Search by rule id and to narrow down the results, enter the rule name and select the status. \
Then, select **Search** (<img src="../../../.gitbook/assets/image (107).png" alt="" data-size="original">).
