# View Rules

View and manage rules created to date.

To view, go to **Data Management** > **Rule Engine** > **View Rules**.

<div align="left"><figure><img src="../../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>

To view a rule, select **View** (![View icon](<../../../.gitbook/assets/image (95).png>)).

To edit a rule, select **Edit** (![Edit icon](<../../../.gitbook/assets/image (96).png>)).

To disable a rule, select **Disable** (![Disable icon](<../../../.gitbook/assets/image (99).png>)). Disabling a rule deactivates it but does not delete it.

To delete a rule, select **Delete** (![Delete icon](<../../../.gitbook/assets/image (98).png>)).
