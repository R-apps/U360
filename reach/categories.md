# Categories

Categories help you categorize your templates in all the communication channels for easy access.

Here's how the categories are managed:

#### Create Category

{% stepper %}
{% step %}
### Create Category — Step 1

Go to **Categories** > **Create Category**
{% endstep %}

{% step %}
### Create Category — Step 2

Give the category a name and select the channel to which it belongs to.
{% endstep %}

{% step %}
### Create Category — Step 3

Then, click **Create Category**
{% endstep %}
{% endstepper %}

#### View Category

{% stepper %}
{% step %}
### View categories

To view the categories created across the channels, navigate to **Categories** > **View Category**
{% endstep %}

{% step %}
### Search for a category

To search for a category, type in a category name, select the channel, and then click Search. The application displays the categories as per your search criteria.
