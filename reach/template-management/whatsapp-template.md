# WhatsApp Template

WhatsApp templates are pre-defined message formats used for automated or mass communication via WhatsApp. These templates ensure consistent messaging, comply with WhatsApp’s guidelines, and streamline customer interactions.

### Create a WhatsApp Template

Personalize your WhatsApp template as required. You can insert plain text, multimedia files, location, dynamic content, action buttons, and more.

{% stepper %}
{% step %}
### Steps to create a template

1. Go to **Template Management** > **WhatsApp Template** > **Create Template**.
2. Select the **WhatsApp Template type** (Message / List).
3. As you configure the template, a preview appears on the right.
4. Save your template.\
   The template gets created and is sent for approval.
{% endstep %}

{% step %}
### Message type

{% tabs %}
{% tab title="Message" %}
* Give the template a name, select the language, [Category,](/broken/pages/2b3e957b4f995d7347019eb05e6a883c594a6e48) Broad topics with similar template features. E.g., 'Technology'. and [Whatsapp Business Id](whatsapp-template.md#) This is the Id generated when you create a Whatspp business account and register it. [Click here](/broken/pages/652473e00c129a2e48439b6c3eb2409611cb73bb) to know more.
* Considering your template design, add header and footer.
* Enter the message to be communicated.
* For dynamic data, you can add variables and provide samples for them. In the header and footer, only one variable can be added, while the message body allows for multiple variables as needed. Click 'Add Variable' to insert a new variable.
* Include Quick Reply (Local/Global) or Call To Action (URL/Call) buttons, if required.
* As you configure the template, a preview appears on the right.
* Then, save your template.
{% endtab %}

{% tab title="List" %}
* Enter the List Title, Header, Message, and Footer.
* Sections help you categorize your list items. Enter the section title and then list the items along with description and expected reply. Click  to add a list item. For more sections, click **Add Section**.
* Check **Global Reply** checkbox, to add a global reply and then enter the reply.
* As you configure the template, a preview appears on the right.
* Finally, save your template.
{% endtab %}
{% endtabs %}
{% endstep %}
