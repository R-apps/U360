# SMS Text Templates

SMS text templates are pre-set message formats used to send consistent, on-brand text messages. They allow quick personalization and help save time and maintain uniformity in your communication campaigns.

### Create a new SMS Text Template

* Go to **Template Management** > **SMS Text Template** > **Create Template**.
* Select the **SMS type** (Transactional / Promotional) and set **Permissions** (All / Sub User / Self) to define who can use it.
* Enter the DLT Entity ID, Template ID, Template Name, Category[^1], Tag[^2], Header, Approval Date, and message in the Message Body. As you type the message, the application gives you a preview of it.

Then, save your template.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Temp-Create SMS template.png" alt=""><figcaption></figcaption></figure></div>

The template gets created and is available under “View Templates”.

### View Templates

All the SMS text templates you created will be available here.

To view, go to **Template Management** > **SMS Text Template** > **View Template**

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Temp-View SMS Templates.png" alt=""><figcaption></figcaption></figure></div>

* To preview a template, hover on it and click View.
* To edit the template, hover on it and click Edit.
* To search for a template, you can choose to search by name/template id/PE id/category/approval date. Type in the search box and click Search.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Temp-Search SMS Templates.png" alt=""><figcaption></figcaption></figure></div>
