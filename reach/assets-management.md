# Assets Management

Assets, also known as resources, is a repository of images that can be used in campaigns. Assets are categorized as:

* **Local Resources**: the assets you have uploaded that are only accessible to you, unless you give permissions to your team to access them.
* **Global Resources**: the assets uploaded by your Administrator that are globally accessible.

You may require a range of assets for different types of campaigns and audiences. Create separate folders to place your assets for each of your campaign channels and needs, keeping your assets organized.

### Local Resources

To access local resources, navigate to **Assets Management > Your Resources**. This displays the list of folders created by you to date. Access a folder to view the assets in it.

#### Upload an Asset

To upload a new asset, follow these steps:

* Create a new folder and give an appropriate name to identify it easily.
* Open the created folder and click <>
* Upload the file from your local storage and add a tag to it for easy recognition.
* Then, set the permissions to specify who can access this asset. Select:
  * **All**, to allow everyone to use it
  * **Sub User**, to allow selected users to use it
  * **Self**, to restrict it for only you to use

\<IMAGE>

Then, click **Upload**, to upload the asset.

To upload an asset into an existing folder, open it and then upload the asset.

{% hint style="info" %}
Only one asset can be uploaded at a time.
{% endhint %}

#### Modify Folder Permissions

To change or update a folder permission, open the folder, and click <>. Set read/write/delete permissions to each of your sub users and then click **Update Permission**.

#### Delete Assets

If you are not using any asset(s), you can choose to delete them.

* To delete individual assets: open the folder, select the assets using the 'Ctrl' key, and then click **Delete Files**.
* To delete an entire folder, click ![](<../.gitbook/assets/Delete CSV Data.png>).

{% hint style="info" %}
Only users with permission to create/edit/delete can perform these actions.
{% endhint %}

### Global Resources

To access global resources, navigate to **Assets Management > Global Resources**. You are not permitted to perform any actions on these assets; you may only use them in your campaigns.
