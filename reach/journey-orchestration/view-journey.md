# View Journey

To view the created scenarios, go to **Journey Orchestration** > **Notification Journey** > **View Journey**.

The platform displays the list with the details - Id, Name, Created By, Journey Activation Date, Journey Status, and Action.

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/Journey Orchestration - View Journey.png" alt=""><figcaption></figcaption></figure></div>

To edit a journey, click ![](<../../.gitbook/assets/Edit icon.png>). Make necessary changes and save it.

To search for a specific journey, search with its name. Use the available search criteria to drilldown your search (By status, Time period, and Created By) to get the desired results.
